## Quick Deploy Options

### 1. GitHub Pages (free & instant)
1. Go to the repo → **Settings** → **Pages**
2. Under **Source**, choose **Deploy from a branch**
3. Select branch `main` and folder `/ (root)`
4. Click **Save**
5. Your site will be live at `https://johnconstant99-dev.github.io/cherrybot-io/`
6. Then add custom domain `cherrybot.io` in the same Pages settings and update your DNS (CNAME or A records as shown by GitHub)

### 2. Vercel
1. Import the repo at [vercel.com/new](https://vercel.com/new)
2. Framework Preset: Other / Static
3. Deploy
4. Add domain `cherrybot.io` in Project → Settings → Domains

> Note: Your Vercel team currently has an overdue balance. Update payment method at https://vercel.com/teams/johnconstant99-devs-projects/settings/billing before deploying there.

### 3. Local preview
```bash
npx serve .
```

## Custom Domain (cherrybot.io)

After enabling Pages or Vercel:

1. In the hosting dashboard add the domain `cherrybot.io` (and optionally `www.cherrybot.io`)
2. At your domain registrar set the DNS records shown by the host
3. Wait for DNS propagation (usually < 30 min)
