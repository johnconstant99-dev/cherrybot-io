## Features

- Dark premium theme matching the Cherry brand
- Hero with live system status
- Live stats section
- Full ecosystem cards (BuyBot, Raid Matrix, Trending, Community Voting)
- Developers section (Security, High Availability, API)
- Mobile-first responsive design
- Tailwind CSS (CDN)

## Deploy

This is a static site. Deploy to Vercel, Netlify, or any static host.

```bash
# Local preview
npx serve .
```

## Custom Domain

After deploying to Vercel:

1. Go to Project → Settings → Domains
2. Add `cherrybot.io` and `www.cherrybot.io`
3. Update DNS as instructed by Vercel
